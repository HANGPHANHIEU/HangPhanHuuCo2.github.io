# HangPhanHuuCo2.github.io

Giải thích:
<link rel="stylesheet" href="style.css">: Dòng này trong <head> sẽ tải và áp dụng file style.css cho toàn bộ trang HTML.

<script src="script.js"></script>: Dòng này ở cuối <body> sẽ chạy file script.js sau khi nội dung HTML được tải, giúp tương tác với các phần tử (như nút, văn bản).

document.getElementById('id_cua_phan_tu'): Lấy một phần tử cụ thể bằng ID của nó.

addEventListener('click', ...): Lắng nghe sự kiện khi nút được nhấn.

textContent và style: Thay đổi nội dung và giao diện (màu sắc) của phần tử.
